The locked 12-field schema (from DEC-investor-profile-schema-frozen — these strings MUST match verbatim):
- Age: int, range [18, 100]
- Gender: Literal["Male", "Female"]
- Education: Literal["High school", "Bachelor", "Master"]    # NOTE: "High school" has lowercase 's' and a space
- MaritalStatus: Literal["Single", "Married"]                # 2 values only; ignore the 4-value drift in src/validation_rules.py
- HouseholdSize: int, range [1, 10]
- Income: float, range [0, 10_000_000]
- InvestmentGoal: Literal["Child education", "Retirement", "Home purchase", "Other"]
- InvestmentHorizon: int, range [1, 50]
- InvestmentCapital: float, range [0, 100_000_000]
- RiskTolerance: Literal["Low", "Medium", "High"]
- FinancialInvolvement: Literal["Low", "Medium", "High"]
- ExperienceYears: int, range [0, 80]

Plus an OPTIONAL field for testability:
- seed: int | None = None

`src.inference.recommend(user: dict) -> dict` returns (verified from src/inference.py lines 139-235):
```
{
    "risk_profile": str,                # "Aggressive" | "Moderate" | "Conservative"
    "allocation":   dict,               # {"equity_pct": float, "bond_pct": float, "alt_pct": float} (sum = 1.0)
    "total_etfs":   int,
    "etf_counts":   dict,               # {"equity": int, "bond": int, "alternative": int}
    "portfolio":    dict,               # {"equity": [str,...], "bond": [str,...], "alternative": [str,...]}
}
```

PascalCase → lowercase mapping `to_inference_dict` MUST emit (from src/inference.py lines 53-65):
- Age → "age"
- Income → "income"
- InvestmentHorizon → "horizon"
- RiskTolerance → "risk_tolerance"
- ExperienceYears → "experience"
- All other 7 fields keep their PascalCase keys.

`RecommendResponse` shape (locked by CON-allocated-assets-jsonb-shape):
- `allocation: dict[str, float]` — keys are tickers, values sum to exactly 1.0 within float tolerance.

Renormalization rule (locked, server-side): after flattening to flat `{ticker: weight}`, `total = sum(flat.values()); flat = {t: w/total for t, w in flat.items()}` if `total > 0`.

Equal-weight-within-asset-class is the chosen intra-class distribution (per RESEARCH "Decision needed" line 676-680 — A2 in Assumptions Log). Per-class percentage from `result["allocation"]` is divided equally across the N tickers in `result["portfolio"][asset_class]`. Document this choice in `api/services/recommend_service.py` docstring; do NOT use AUM-weighted intra-class in Phase 1.
